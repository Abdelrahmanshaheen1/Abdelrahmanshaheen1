### 🚀 Featured projects

🔐 **[Ethical Hacking — Pentesting Labs](https://github.com/Abdelrahmanshaheen1/Ethical-Hacking-Pentesting-Labs)**
Seven hands-on labs against intentionally vulnerable training machines, covering the full attack chain: OSINT/recon → initial exploitation → privilege escalation → post-exploitation persistence.

🎯 **[OWASP Juice Shop — Security Assessment](https://github.com/Abdelrahmanshaheen1/OWASP-Juice-Shop-Security-Assessment)**
A full client-side and server-side security assessment of a deliberately vulnerable web app — 12 findings total, including SQL injection auth bypass, IDOR, privilege escalation via payload tampering, and JWT `alg:none` forgery.

🏥 **[Healthcare Fraud Detection (ML)](https://github.com/Abdelrahmanshaheen1/Healthcare-Fraud-Detection-ML)**
End-to-end fraud detection pipeline comparing five classification models (Logistic Regression, XGBoost, Random Forest, SVM, Decision Tree), with full ROC-AUC/precision/recall evaluation rather than just headline accuracy.

🔒 **[Secure Auction — Pedersen Commitments](https://github.com/Abdelrahmanshaheen1/Secure-Auction-Pedersen-Commitments)**
A cryptographic sealed-bid auction protocol built from scratch: secret sharing, Pedersen commitments, zero-knowledge range proofs, and secure multi-party computation.

🧠 **[Advanced Machine Learning Projects](https://github.com/Abdelrahmanshaheen1/Advanced-Machine-Learning-Projects)**
Three projects in one: clustering validation (Silhouette/Davies-Bouldin/Calinski-Harabasz), image captioning (InceptionV3 + LSTM), and emotion classification comparing an RNN, a fine-tuned transformer, and LLM prompting strategies.
